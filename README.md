# Portafolio de Alejandro Vargas Vega

Portafolio personal estático desarrollado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño visual y estilos responsivos.
- `script.js`: menú móvil y año automático.
- `ale.png`: fotografía de perfil (debe agregarse manualmente).

## Publicación con GitHub Pages
1. Sube los archivos directamente a la raíz del repositorio.
2. Coloca `ale.png` en esa misma raíz, junto a `index.html`.
3. Abre **Settings > Pages**.
4. Selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`.
5. Guarda y espera a que termine la publicación.

Estructura final:
```text
repositorio/
├── index.html
├── styles.css
├── script.js
├── ale.png
└── README.md
```

La fotografía se referencia como `./ale.png`. Respeta exactamente el nombre y la extensión.
